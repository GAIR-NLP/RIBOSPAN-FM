# RiboGRAM inference

**Version 1.0.0**

This repository provides a compact inference implementation for the RiboGRAM
model family. It supports RNA embeddings, RiboGRAM attention visualization,
13- and 88-class ncRNA classification, and RNA interaction prediction through
one command-line entry point: `infer.py`.

## Repository layout

```text
code/
├── infer.py
├── requirements.sh
├── README.md
├── test.ipynb
├── test_samples.json
├── checkpoints/
├── ribogram/
└── test_outputs/
```

- `ribogram/` contains the model, alphabet, batch converters, and checkpoint
  loader.
- `test.ipynb` is an executed, hierarchical inference example.
- `test_samples.json` records the provenance of the real labelled
  classification and interaction examples.
- `test_outputs/` contains the compact outputs generated by the notebook.

## Installation

The release was validated with Python 3.8.18, PyTorch 1.13.1+cu116, and an
NVIDIA A100 GPU. From the directory containing this README, run:

```bash
bash requirements.sh
```

The supplied installer uses the CUDA 11.6 PyTorch wheel. Install a
platform-appropriate PyTorch build separately if CUDA 11.6 is not available.
GPU inference is strongly recommended because each full model checkpoint is
approximately 3.16 GiB before runtime activations.

## Download model checkpoints

Model weights are not downloaded automatically. Download the checkpoint files
needed for your task from the official
[RiboGRAM download page](https://www.ultrarnalab.com/ribogram.php), then place
them directly in:

```text
code/checkpoints/
```

Filenames are case-sensitive on Linux. Do not rename the files: the default
paths in `infer.py` use the exact names listed below.

### Files included in the minimal package

The minimal release needs only these three files:

```text
checkpoints/
├── RiboGRAM.pkl
├── ribogram_ncrna13_head.pt
└── ribogram_ncrna88_head.pt
```

This set supports RiboGRAM embeddings, RiboGRAM attention maps, ncRNA
13-category classification, and ncRNA 88-family classification.

### Checkpoint required for each task

Download only the files required for the task you plan to run.

| Task | CLI selection | Required file(s) in `checkpoints/` |
|---|---|---|
| RiboGRAM sequence embeddings | `embedding --architecture RiboGRAM` | `RiboGRAM.pkl` |
| PLM-CDS sequence embeddings | `embedding --architecture PLM-CDS` | `PLM-CDS.pkl` |
| PLM-mRNA sequence embeddings | `embedding --architecture PLM-mRNA` | `PLM-mRNA.pkl` |
| RiboGRAM attention map | `attention --architecture RiboGRAM` | `RiboGRAM.pkl` |
| 13-category ncRNA classification | `ncrna13` | `RiboGRAM.pkl` and `ribogram_ncrna13_head.pt` |
| 88-family ncRNA classification | `ncrna88` | `RiboGRAM.pkl` and `ribogram_ncrna88_head.pt` |
| RNA-protein interaction (RPI) | `interaction --architecture RiboGRAM-RPI` | `RiboGRAM-RPI.pkl` |
| RNA-protein interaction (RPIplus) | `interaction --architecture RiboGRAM-RPIplus` | `RiboGRAM-RPI_plus.pkl` |
| RNA-RNA interaction (RRI/RISE) | `interaction --architecture RiboGRAM-RRI` | `RiboGRAM-RRI.pkl` |
| RNA-chromatin interaction (RCI) | `interaction --architecture RiboGRAM-RCI` | `RiboGRAM-RCI.pkl` |

To rerun every model-specific section of `test.ipynb`, download all files in
the table. When an optional checkpoint is absent, the corresponding notebook
test reports `SKIP` rather than preventing the core RiboGRAM examples from
running.

Custom checkpoint locations can be supplied with `--checkpoint`. The ncRNA
commands use separate `--backbone` and `--head` options.

## Supported tasks

| Command | Input | Main output |
|---|---|---|
| `embedding` | One or more RNA sequences | Layer-specific token embeddings and a mean embedding |
| `attention` | One RNA or a built-in manuscript case | Selected-head attention, APC matrix, and optional heatmap |
| `ncrna13` | One or more RNA sequences | Probabilities over 13 broad ncRNA categories |
| `ncrna88` | One or more RNA sequences | Probabilities over 88 Rfam families |
| `interaction` | RNA plus protein, RNA, or DNA | Binary interaction probability and prediction |

## Command-line examples

Run commands from the directory containing `infer.py`. Default checkpoint
paths are resolved relative to `infer.py`.

### 1. Sequence embeddings

```bash
python infer.py embedding \
  --architecture RiboGRAM \
  --sequence rna-1=GGAGCUCAGCCUUCACUGCG \
  --sequence rna-2=GCGUACGUAGCUAGCUACGU \
  --layer 12 \
  --device auto \
  --output outputs/RiboGRAM_embeddings.pt
```

To use a control model, change `--architecture` to `PLM-CDS` or `PLM-mRNA`
and download the corresponding checkpoint first. For every sequence, the
command prints both dimensions:

```text
rna-1: token_embeddings=(20, 1280), mean_embedding=(1280,)
```

`token_embeddings` excludes `<cls>`, `<eos>`, and padding tokens, so its first
dimension equals the normalized RNA length. The PT file stores the token
matrix, mean vector, normalized sequence, label, and layer number.

### 2. RiboGRAM attention maps

Generate the three manuscript cases (CD-box, tRNA, and H/ACA-box):

```bash
python infer.py attention \
  --architecture RiboGRAM \
  --case all \
  --layer 12 \
  --head 20 \
  --symmetrize \
  --plot \
  --output-dir outputs/attention
```

Custom RNA:

```bash
python infer.py attention \
  --architecture RiboGRAM \
  --sequence ACGUACGUACGU \
  --name custom-rna \
  --layer 12 \
  --head 20 \
  --symmetrize \
  --plot \
  --output-dir outputs/attention
```

The manuscript visualization uses Layer 12, Head 20 (the final head),
symmetric averaging, positive-only average-product correction (APC), and the
`magma` colour map. Zero values are black and the strongest values are
yellow-white. Sequence coordinates are one-based; position 1 is at the top of
the y-axis and at the left of the x-axis.

Each CLI case can export:

- `.pt`: complete tensor bundle, including all heads;
- `.csv`: APC-adjusted selected-head matrix;
- `.json`: sequence and extraction metadata;
- `.png`: 300-dpi heatmap when `--plot` is supplied.

### 3. Thirteen-category ncRNA classification

Required files: `RiboGRAM.pkl` and `ribogram_ncrna13_head.pt`.

```bash
python infer.py ncrna13 \
  --sequence example=GCCGGGGUCGCCUAGCCUGGUCAAGGGCGCC \
  --device auto \
  --output outputs/ncrna13.json
```

The classifier uses frozen Layer-12 RiboGRAM features. The JSON result includes
the predicted category, confidence, and all 13 probabilities.

### 4. Eighty-eight-family ncRNA classification

Required files: `RiboGRAM.pkl` and `ribogram_ncrna88_head.pt`.

```bash
python infer.py ncrna88 \
  --sequence example=GCCGGGGUCGCCUAGCCUGGUCAAGGGCGCC \
  --device auto \
  --output outputs/ncrna88.json
```

The JSON result includes the predicted Rfam accession, confidence, and all 88
probabilities.

### 5. Interaction prediction

Each interaction task uses one self-contained fine-tuned checkpoint; the base
`RiboGRAM.pkl` file is not additionally required.

RNA-protein interaction:

```bash
python infer.py interaction \
  --architecture RiboGRAM-RPI \
  --rna ACGUACGUACGU \
  --partner MARGKKIGYS \
  --output outputs/rpi.json
```

Expanded RNA-protein interaction model:

```bash
python infer.py interaction \
  --architecture RiboGRAM-RPIplus \
  --rna ACGUACGUACGU \
  --partner MARGKKIGYS \
  --output outputs/rpiplus.json
```

RNA-RNA interaction:

```bash
python infer.py interaction \
  --architecture RiboGRAM-RRI \
  --rna ACGUACGU \
  --partner UGCAUGCA \
  --output outputs/rri.json
```

RNA-chromatin interaction:

```bash
python infer.py interaction \
  --architecture RiboGRAM-RCI \
  --rna ACGUACGU \
  --partner ACGTACGT \
  --output outputs/rci.json
```

For RCI, `--partner` is the forward DNA sequence. Its reverse complement is
constructed automatically. The default binary threshold is 0.5 and can be
changed with `--threshold`.

## Test notebook

`test.ipynb` demonstrates:

1. checkpoint discovery;
2. RiboGRAM, PLM-CDS, and PLM-mRNA embedding dimensions;
3. RiboGRAM Layer-12/Head-20 attention for the three manuscript cases;
4. ncRNA-13 and ncRNA-88 classification;
5. RPI, RPIplus, RRI, and RCI prediction;
6. a final PASS/SKIP summary and output-file inventory.

The classification and interaction examples are real labelled records. Their
dataset identifiers, labels, splits, original paths, and reference scripts are
recorded in `test_samples.json`.

To keep the test output compact, `test_outputs/attention/` contains only
`RiboGRAM_manuscript_cases.png`. The three embedding PT files are retained in
`test_outputs/embeddings/`, while their exact token and mean dimensions are
printed in the notebook.

## Python API

```python
from infer import inference_ncrna88, inference_rpi

families = inference_ncrna88(
    "checkpoints/RiboGRAM.pkl",
    "checkpoints/ribogram_ncrna88_head.pt",
    [("rna-1", "GCCGGGGUCGCCUAGCCUGGUCAAGGGCGCC")],
    device="cuda",
)

interactions = inference_rpi(
    "checkpoints/RiboGRAM-RPI_plus.pkl",
    [("pair-1", "ACGUACGU", "MARGKKIGYS")],
    rpiplus=True,
    device="cuda",
)
```

Public inference functions:

- `inference_sequence_embeddings`
- `inference_attention` and `inference_attention_batch`
- `inference_ncrna_classification`
- `inference_ncrna13` and `inference_ncrna88`
- `inference_interaction`
- `inference_rpi`, `inference_rri`, and `inference_rci`

## Input conventions

- RNA is uppercased and `T` is converted to `U`.
- Protein is uppercased.
- DNA is uppercased and `U` is converted to `T`.
- Whitespace inside sequences is removed.
- Unsupported symbols map to `<unk>`.
- RPI layout: `<cls> RNA <eos> protein <eos>`.
- RRI layout: `<cls> RNA1 <eos> RNA2 <eos>`.
- RCI layout: `<cls> RNA <eos> DNA <eos> reverse-complement(DNA) <eos>`.

## Deployment and security notes

- `--device auto` uses CUDA when available and otherwise falls back to CPU.
- Attention memory grows quadratically with RNA length.
- A CLI invocation loads one checkpoint and then exits. A web service should
  keep frequently used models resident instead of reloading them per request.
- Do not expose arbitrary checkpoint paths to untrusted web clients.
- PyTorch checkpoints use Python serialization. Download them only from the
  official RiboGRAM page and do not load untrusted files.
