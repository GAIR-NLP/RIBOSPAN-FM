# Source code

`scripts/model_src.py` in each project puts this directory on `sys.path`.

```text
model_src/
  ribospan/     # RIBOSPAN
  rnabert/      # AIDO.RNA-CDS
  HydraRNA/     # fairseq HydraRNA
  RiNALMo/      # RiNALMo
```

RNA-FM is the `rna-fm` pip package from `setup.sh`, not a tree here.
